# Every scheme below uses ANSI-X9.63-KDF with SHA-1, HMAC-SHA-1-160 with
# 20-octet keys, the XOR encryption scheme with SEC 1 v1.0's key layout

# of section 5.1.1 step 9), compressed points, and no SharedInfo1/SharedInfo2.
#
# The values were copied from `pdftotext -layout` output by a script, not
# retyped; spacing inside a value is GEC 2's grouping. Keys ending in _dec are
# printed in decimal by GEC 2; every other value is hexadecimal. Each value is
# taken from the encryption operation for U (subsection x.3): dV and QV from
# key deployment step 1.1 and the compressed QV of step 2; M from input 1; k
# from step 1.1; R from step 2; Z from step 4; K from step 5.5; EK and MK from
# step 6; EM from step 7.4; D from step 8.3; C from the Output.
#
# Erratum in the source: step 1 of each decryption operation for V prints a
# tag D that differs from the D inside the C it parses (3.1.4: 13B59208...,
# 3.2.4: E5904578...), then computes D' equal to the encryption's D and
# reports "D' = D, OK". Only the encryption-side values are used here.
